### Annotation Patterns (Validated ✅)

#### Repositories: @lazySingleton
```dart
// Reference: https://pub.dev/packages/injectable#registering-singletons
import 'package:injectable/injectable.dart';

@lazySingleton
class ProductRepo {
  final NetworkService _networkService;
  ProductRepo(this._networkService); // Constructor injection
}
```

**Validation**: ✅ Matches [Injectable Singletons](https://pub.dev/packages/injectable#registering-singletons)
- `@lazySingleton` → `getIt.registerLazySingleton(() => ProductRepo())`
- Lazy initialization (created on first access)

#### Cubits: @injectable (Factory)
```dart
// Reference: https://pub.dev/packages/injectable#registering-factories
import 'package:injectable/injectable.dart';
import 'package:flutter_bloc/flutter_bloc.dart';

@injectable
class ProductListCubit extends Cubit<ProductListState> {
  final ProductRepo _productRepo;
  ProductListCubit(this._productRepo) : super(ProductListInitial());
}
```

**Validation**: ✅ Matches [Injectable Factories](https://pub.dev/packages/injectable#registering-factories)
- `@injectable` → `getIt.registerFactory(() => ProductListCubit())`
- New instance on each access (proper for cubits)

#### Services: @singleton
```dart
// Reference: https://pub.dev/packages/injectable#registering-singletons
import 'package:injectable/injectable.dart';

@singleton
class NetworkService {
  final Dio _dio;
  NetworkService(this._dio);
}
```

**Validation**: ✅ Matches [Injectable Singletons](https://pub.dev/packages/injectable#registering-singletons)
- `@singleton` → `getIt.registerSingleton(NetworkService())`
- Eager initialization (created immediately)

## 🎯 Lifecycle Comparison

| Annotation | GetIt Registration | Lifecycle | Use For |
|------------|-------------------|-----------|---------|
| `@injectable` | `registerFactory()` | New instance each time | Cubits, Controllers |
| `@singleton` | `registerSingleton()` | Single instance (eager) | Services created at startup |
| `@lazySingleton` | `registerLazySingleton()` | Single instance (lazy) | Repositories, heavy services |

**Reference**: [Injectable Registering Singletons](https://pub.dev/packages/injectable#registering-singletons)

## 🎯 Best Practices (from Official Docs)

1. ✅ Use `@injectable` for factories (new instance each time)
2. ✅ Use `@lazySingleton` for expensive-to-create singletons
3. ✅ Use `@singleton` for eager singletons needed at startup
4. ✅ Constructor injection for dependencies
5. ✅ `getIt.reset()` in test setUp
6. ✅ Keep `@InjectableInit` in separate file from app logic
7. ✅ Use `preferRelativeImports: true` for better refactoring
8. ✅ Run `build_runner` after adding new @injectable classes
