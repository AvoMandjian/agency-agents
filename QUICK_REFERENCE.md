## 🔧 Engineering (7 Agents)

| Agent | Role | When to Use |
|-------|------|------------|
| **frontend-developer** | Flutter UI Developer | Building screens, implementing BLoC state management, creating reusable widgets with Shadcn Flutter |
| **mobile-app-builder** | Cross-Platform App Builder | Creating mobile apps for Android/iOS, offline-first architecture, platform-specific features |
| **backend-architect** | Serverpod Backend Architect | Designing APIs, database schemas, Serverpod endpoints, PostgreSQL optimization |
| **senior-developer** | Senior Technical Lead | Code reviews, architectural decisions, mentoring, complex refactoring |
| **rapid-prototyper** | MVP Builder | Building functional MVPs in 1-2 weeks, rapid iteration, proof-of-concept validation |
| **ai-engineer** | AI/ML Integration Specialist | Integrating ML models, AI features, recommendation systems, natural language processing |
| **devops-automator** | DevOps & Infrastructure | CI/CD pipelines, automated testing, deployment automation, cloud infrastructure |

**Common Patterns**: BLoC with sealed classes, Repository pattern with injected NetworkService, GetIt/Injectable DI, AutoRoute navigation, Mason bricks

## 📝 Syntax Quick Reference

### How to Reference Agents

```
@agency-agents/[division]/[agent-name].md
```

**Examples**:
```
@agency-agents/engineering/engineering-frontend-developer.md
@agency-agents/testing/testing-evidence-collector.md
@agency-agents/design/design-ux-architect.md
```

### How to Provide Context

```
@memory_bank_dual/rules/memory-bank.mdc
@agency-agents/.templates/flutter-patterns.md
@agency-agents/.templates/PACKAGES_REFERENCE.md
```

### Request Structure Template

```
@agency-agents/[division]/[agent].md
@memory_bank_dual/rules/memory-bank.mdc

[Clear description of what you need]

Requirements:
- [Specific requirement 1]
- [Specific requirement 2]
- [Specific requirement 3]

Context:
- Flutter version: 3.27+
- Target platforms: Android, iOS
- Current architecture: [BLoC, Serverpod, etc.]

Please provide:
1. [Expected deliverable 1]
2. [Expected deliverable 2]
```

## 🎯 Quick Tips

✅ **DO**:
- Be specific about requirements
- Provide Flutter version and target platforms
- Reference project conventions (`@agency-agents/.templates/flutter-patterns.md`)
- Request complete, compilable examples
- Ask for rationale and trade-offs

❌ **DON'T**:
- Make vague requests ("make it better")
- Skip context (Flutter version, architecture, constraints)
- Ask multiple unrelated things at once
- Ignore established patterns
- Expect agents to "just know" your preferences
