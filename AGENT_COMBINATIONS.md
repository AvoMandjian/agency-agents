# Flutter Agency Agents - Pre-Defined Agent Teams

**🤝 Agent Team Combinations for Common Scenarios | Version 1.0.0 | Updated: Oct 17, 2025**

---

## 📖 Introduction

This document provides pre-defined agent teams ("squads") for common Flutter development scenarios. Each team includes specific agents, their roles, expected timeline, and deliverables.

### How to Use Agent Teams

1. **Identify Your Scenario**: Match your goal to a pre-defined team
2. **Invoke Team Lead**: Start with the first agent in sequence
3. **Follow Workflow**: Each agent hands off to the next per team structure
4. **Track Progress**: Monitor deliverables at each handoff
5. **Adjust as Needed**: Add/remove agents based on specific project needs

## 🚀 MVP Squad (2-Week Full Product Launch)

**Goal**: Build complete Flutter MVP from requirements to App Store launch

### Team Composition (7 Agents)

```
1. Senior Project Manager → Task breakdown, timeline
2. Flutter UX Architect → User flows, wireframes
3. Flutter UI Designer → Visual design, design system
4. Flutter Frontend Developer → UI implementation
5. Flutter Backend Architect → Serverpod APIs, database
6. Flutter Evidence QA → Testing, validation
7. Flutter Reality Checker → Production approval
```

### Timeline: 14 Days

- **Days 1-2**: Requirements & Design (PM, UX, UI)
- **Days 3-10**: Development (Frontend + Backend parallel)
- **Days 11-12**: Integration & Testing (QA)
- **Day 13**: Performance validation (Evidence QA + Performance Benchmarker)
- **Day 14**: Final approval & App Store prep (Reality Checker + ASO)

### Deliverables

- ✅ Functional Flutter app (Android + iOS)
- ✅ Serverpod backend with PostgreSQL
- ✅ Firebase Analytics + Crashlytics integrated
- ✅ Test coverage >80% for business logic
- ✅ App Store listing ready
- ✅ Production deployment approved

### Usage

```
@agency-agents/project-management/project-manager-senior.md
@memory_bank_dual/rules/memory-bank.mdc

I need to build a [app description] MVP in 2 weeks.

Core features:
- [Feature 1]
- [Feature 2]
- [Feature 3]

Tech requirements:
- Flutter (Android + iOS)
- Serverpod + PostgreSQL backend
- Firebase Auth + Analytics

Please create comprehensive task breakdown for 2-week MVP delivery.
```

## 🔧 Feature Factory (1-Week Feature Development)

**Goal**: Add new feature to existing Flutter app in one sprint

### Team Composition (5 Agents)

```
1. Flutter Product Sprint Prioritizer → Feature validation
2. Flutter UX Architect → User flow design
3. Flutter Frontend Developer → Implementation
4. Flutter Backend Architect → API endpoints (if needed)
5. Flutter Evidence QA → Testing & validation
```

### Timeline: 5-7 Days

- **Day 1**: Prioritization & UX (Prioritizer, UX Architect)
- **Days 2-4**: Implementation (Frontend + Backend parallel)
- **Day 5**: Testing & bug fixes (Evidence QA)
- **Day 5 PM**: Final approval (Reality Checker)

### Deliverables

- ✅ Feature implementation complete
- ✅ Unit + widget tests (>80% coverage)
- ✅ Integration with existing app seamless
- ✅ Documentation updated
- ✅ Production ready

### Usage

```
@agency-agents/product/product-sprint-prioritizer.md
@memory_bank_dual/rules/memory-bank.mdc

I want to add [feature name] to our existing app.

Feature requirements:
- [Requirement 1]
- [Requirement 2]
- [Requirement 3]

Validate this feature and provide prioritization recommendation.
```

## 🛡️ Quality Guardians (3-5 Days Comprehensive QA)

**Goal**: Comprehensive testing and validation before production release

### Team Composition (6 Agents)

```
1. Flutter Evidence QA → Functional testing (lead)
2. Flutter API Tester → Backend validation
3. Flutter Performance Benchmarker → Performance testing
4. Widget Test Specialist → UI validation (use Evidence QA)
5. Flutter Test Results Analyzer → Results synthesis
6. Flutter Reality Checker → Final approval
```

### Timeline: 3-5 Days

- **Day 1**: Functional testing (Evidence QA)
- **Days 2-3**: Specialized testing (API, Performance, Widget)
- **Day 4**: Bug fixes, re-testing
- **Day 5**: Analysis & approval (Analyzer, Reality Checker)

### Deliverables

- ✅ Comprehensive test report
- ✅ All critical bugs fixed
- ✅ Performance targets met (60fps, <2s startup, <150MB memory)
- ✅ Test coverage >80%
- ✅ Production approval granted

### Usage

```
@agency-agents/testing/testing-evidence-collector.md
@memory_bank_dual/rules/memory-bank.mdc

Feature [name] is development-complete. Please conduct comprehensive QA.

Scope:
- [Screen 1]
- [Screen 2]
- [API endpoints]

Acceptance criteria:
- [Criteria 1]
- [Criteria 2]
```

## ⚡ Performance Ninjas (2-3 Days Optimization)

**Goal**: Diagnose and fix performance issues

### Team Composition (4 Agents)

```
1. Flutter Performance Benchmarker → Issue analysis (lead)
2. Flutter Frontend Developer → UI optimization
3. Flutter Backend Architect → API optimization
4. Flutter Senior Developer → Architecture review (if needed)
```

### Timeline: 2-3 Days

- **Day 1 AM**: Profiling & analysis (Performance Benchmarker)
- **Day 1 PM - Day 2**: Optimization (Frontend/Backend parallel)
- **Day 3**: Re-testing & validation

### Deliverables

- ✅ Performance issue diagnosed
- ✅ Optimization implemented
- ✅ Targets achieved (60fps, <2s startup, <150MB memory)
- ✅ No regressions introduced
- ✅ Performance validation report

### Usage

```
@agency-agents/testing/testing-performance-benchmarker.md
@memory_bank_dual/rules/memory-bank.mdc

Performance issue: [description]

Current metrics:
- Frame rate: [X fps]
- Startup time: [X seconds]
- Memory usage: [X MB]

Target metrics:
- 60fps scrolling
- <2s startup
- <150MB memory

Please analyze and provide optimization recommendations.
```

**Goal**: Launch app or major feature with comprehensive marketing

### Team Composition (5-8 Agents)

```

1. Flutter Social Media Strategist → Campaign strategy (lead)
2. Flutter Content Creator → Written content
3. Flutter Visual Storyteller → Visual assets
4. Flutter App Store Optimizer → ASO
5. Flutter Analytics Reporter → Performance tracking

Platform Specialists (As Needed):
6. Flutter Instagram Curator → Instagram campaign
7. Flutter Twitter Engager → Twitter/X campaign  
8. Flutter TikTok Strategist → TikTok campaign
```

### Timeline: 1-2 Weeks

- **Week 1 Days 1-2**: Strategy & content creation
- **Week 1 Days 3-7**: Campaign execution begins
- **Week 2**: Monitoring, optimization, scaling

### Deliverables

- ✅ Multi-platform marketing strategy
- ✅ Content calendar (2-4 weeks)
- ✅ Visual assets (screenshots, videos, graphics)
- ✅ App Store listing optimized
- ✅ Campaign performance dashboard

```
@agency-agents/marketing/marketing-social-media-strategist.md

Launching [app name] in [timeframe].

App details:
- Category: [category]
- Target audience: [audience]
- Key features: [features]
- Budget: [budget]

Please create comprehensive launch marketing strategy.
```
